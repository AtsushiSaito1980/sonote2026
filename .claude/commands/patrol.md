# トリガ巡回

`config/sources.yml` の**6つの棚を全部**スキャンする（1棚でも飛ばすとテーマが偏る）。

1. 価格・営業・商品（オズボーン系の日次ニュース）
2. 制度（官報・審議会・パブコメ・条例審議）
3. 技術の節目（量産開始・実用化・受賞・特許切れ・価格逆転）
4. 提携（資本業務提携・協業・老舗×スタートアップ）
5. 決算（四半期ごとに在庫事例の再トリガ確認）
6. 人物・動機の節目（上場・資金調達・受賞・周年・事業承継・書籍出版）

## 出す前に必ず照合する

`ledger/episodes_log.csv` と `library/operations.md` を読み、

- 過去回と同じ題材は除外（T3定点観測を除く）
- 直近5回と同じ手・同じ主要業界は避ける
- **未使用の手**（operations.md の「使用済み」が空欄）を優先
- **今週まだ動機回（narrative）が無ければ、棚⑥から1本必ず入れる**
- 今週まだ技術・提携系が無ければ、棚③④から1本入れる

## 出力（5〜7件）

各候補について：`トリガ（媒体・発表名・公開日）／手の候補（OP）／動機の有無（MO）／風（TW）／想定ホスト／なぜ今か／裏取りの難易度`
最後に「今週の充足状況（動機回◯本・技術系◯本・未使用の手）」を1行で添える。

トリガの無い良ネタは `ledger/episodes_log.csv` に `trigger_wait` で追記して寝かせる。
