# 事実カード化（表現の遮断層）

**この工程の目的は要約ではなく、原文の表現を物理的に捨てること。** 以降のレイヤーには facts.yaml と quote card しか渡さない。要約＝翻案の経路を構造的に閉じる。

## 手順

1. `episodes/<id>/sources/` を読む（一次・準一次情報：公式リリース、官公庁資料、決算、本人インタビュー）
2. 各事実を以下のスキーマに落とす。**各フィールドは短い名詞句・数値のみ（15字以内）。形容詞・評価語・比喩の記入を禁止**

```yaml
facts:
  - {id: F01, who: ◯◯, what: △△, value: 数値や短い名詞句, when: 2026-07, source_url: "...", confirmed_by: 2, anchor: true}
```

3. 発言は quote card として別管理（趣旨・話者の役職・出典）。**逐語引用ではなく趣旨。個人名は原則使わず役職で扱う**
4. キー数字は `confirmed_by >= 2`（2ソース以上または一次資料）。満たさないものは notes に「原典での再確認を推奨」と書く
5. 採用できなかった主張は `rejected:` に理由つきで残す（後の判断材料になる）

## 禁止
- sources に無い数字・固有名詞・発言を作らない
- 原文の言い回しをそのまま value に入れない
