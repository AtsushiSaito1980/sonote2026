# 構成表（香月の仕事）

台本をいきなり書かない。パート別の要点・字数割当・使用する事実IDを先に決める。

## 手順

1. `brief.yaml` の episode_type / format / density を確認し、`library/episode_types.md` の該当する型（型1/型2/型3）を選ぶ
2. パートごとに、字数目安・使う事実ID・言いたいこと（1行）を書く
3. **解剖パートは「条件＋動作」の3箇条**にする。警句にしない
   - ⭕「売上が減った時間を見つけたら、客がどの時間に移ったかを先に調べる」
   - ❌「客は消えない、時間に隠れる」
4. 他業界への応用例を1つ以上、どのパートで出すか決める
5. トリガの時点をどこで口頭明示するか決める（「先月の半ばの発表で」等）

## 出力
`episodes/<id>/outline.md`
