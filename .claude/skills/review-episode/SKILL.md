# 検査（香月の仕事）

## 手順

1. **必ず最初に実行**：`python3 scripts/check.py episodes/<id>`
2. FAIL があれば write-script に差し戻す（最大2周。2周で通らなければ人間へエスカレーション）
3. スクリプトが「－（要確認）」を出した項目を、モデルが文脈で判断する：

| 項目 | 判断の仕方 |
|---|---|
| 数字の系統数 | 同一施策・同一統計を構成する数値群は1系統。列挙の談話標識（一つ、二つ）は対象外 |
| 固有名詞 | 純粋な地名は対象外。人物は続柄・役職で扱えているか |
| キメ台詞 | 対句・体言止めの要約・ポエム調ならNG。事実の平叙なら可 |
| 例え話 | 他業界への応用例は対象外（芸の本体） |
| トリガ鮮度 | anchor が1ヶ月以内か。超える事実に時期の明示があるか |
| 台帳照合 | ledger/episodes_log.csv と題材重複・直近5回の手/業界の連続 |

4. `review.md` に、**数え方の規約と判断の根拠**を必ず書く（後で基準がぶれないため）
5. 事実面：単独出典・要約経由の数字は「原典での再確認を推奨」と明記する
6. 読みチェック語を最大4つ挙げる（TTS生成後に人間が確認するもの）
7. 制作日依存の表現（「きょうは日曜」「つい二日前」）があれば、差し替え指示を書く
