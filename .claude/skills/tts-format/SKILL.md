# TTS完成稿への変換

**script_tts.txt は、ElevenLabs のテキスト欄にそのまま貼って生成できる完成稿。**
モデルは **Eleven v3**（音声タグ `[bright]` 等が効く世代）を前提にする。

## 規則

1. 見出し・話者ラベル・注釈・メタ情報を全部落とす（本文とタグのみ）
2. **数字は漢数字**に開く（2,000円 → 二千円）。英字・略語は `library/dictionary.yaml` でカタカナ展開
3. 感情タグは**段落頭に1つまで、全体で8〜10個**（6分尺）。感情が切り替わる段落の頭に置く
   - 使用セット：`[bright] [curious] [serious] [excited] [thoughtful] [warm] [calm]`
4. **三点リーダー「…」禁止**（そのまま読まれる事故）
5. **半角スペースでの分かち書き禁止**（ブツ切りの原因）
6. 漢字はテスト駆動で開く。先回りで全部開かない。誤読した語だけ後から dictionary に追記
7. 駄洒落になっている漢字は開かない（家系図）

## 間の作り方（2026-08 実機テストの結論）

**`<break time="..." />` は使わない。**Eleven v3 は SSML の break タグに対応しておらず、
実機で効かなかった。`[pause]` 系も、多用すると**音質が変わり、効果も薄い**ことを確認済み。

間は次の順で作る。**上ほど確実。**

| 手段 | 使いどころ |
|---|---|
| **① 句点で切る** | 読点でつなぐより句点。TTS は句点で確実に区切る |
| **② 一語だけの文** | 「ところが。」「荏原製作所。」社名・接続詞・言い切りを単独の文に |
| **③ フィラー** | 「えー」「うん」は時間を食う＝実質の間になる。しかも自然（台本側の仕事） |
| **④ 段落（空行）** | 話のかたまりの区切り |
| **⑤ `[pause]` `[long pause]`** | **ここぞの場所だけ。1本あたり合わせて5個まで** |

### `[pause]` を置いてよい場所（5個まで）

多用すると音質が落ちるので、**本当に止めたい場所だけ**に絞る。

- `[long pause]`：**解剖パートに入る直前**（「さて。」の後）／**回の芯を言う直前**
- `[pause]`：**咀嚼の折れ目**（「ところが。」の後）／**つかみの言い切りの後**（「荏原製作所。」の後）

それ以外の間は、①〜④で作る。**段落ごとに機械的に入れない。**

### それでも足りないとき

テキストだけでは「ここぞの3秒の沈黙」は作れない。必要なら
**章ごとに分けて生成し、あとで無音をつなぐ**（切れ目が自然に無音になる）。

## 生成後（人間の仕事・省略不可）

通し聴取 → **誤読した語を `library/dictionary.yaml` に追記**。

**その回で開いた語は、辞書に必ず書き戻す。**その場で開いて終わりにすると資産にならない。
実際、ABF→エービーエフ、JGreeX→ジェイグリークス、法定外→ほうていがい は
開いたのに辞書へ戻っておらず、毎回ゼロから判断していた。
