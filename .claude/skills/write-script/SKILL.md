# 台本執筆

## 書く前に必ず読む（順番厳守）

1. `CLAUDE.md` の禁止事項
2. `personas/{host}.md`（brief の host を見る）
3. **`episodes/` の直近2〜3本の script_draft.md** ← 文体はここで決まる。ペルソナ文書だけでは再現しない
   - 良い基準：ep003（聞き上手の型）ep005（動機回）ep020（**間とフィラーの基準形・2026-08改**）
   - **ep001 は旧文体（キメ台詞が残る）。文体の参考にしない**
   - **ep012〜ep018 は文が長く間が足りない。長さの参考にしない**

## 書き方の核

**わかっていく過程を書く。** 素朴な疑問 → 調べる/聞く → 伝聞の答え → 自分の言葉と生活の実例で言い直す → 「ってことですよね」で確認。

- 出典は主語なしの取材話法のみ（`調べてみたら` `聞いてみたところ` ＋ `〜だそうです`）。**「香月」は絶対に出さない**
- 知らなかったことは知らないと言う（1回以上）。ただし卑下は書かない
- 情報を3つ連射したら、素朴なひと言で息継ぎ。**「言い当て」でキメない**
- 専門用語は初出で一度だけ日常語に翻訳（PIT作業→整備の受付）
- 数字は耳用に丸める。正確値は note に回す
- 1ヶ月を超える事実は「去年の八月」「一昨年の調査」と時期を明示

## 咀嚼の3拍（1回に3箇所・省略不可）

**「頭の良い芸人が咀嚼して教えてくれる」の正体はこれ。**事実をそのまま置かず、
自分が理解する過程を演じる。1つの事実につき3拍を使う。

| 拍 | 中身 | 書き方の例 |
|---|---|---|
| 1 | **思い込みを言う** | 私、和牛とお酒だと思ってました／ポンプ屋さんが出てくる場所じゃないよなあ、って |
| 2 | **訂正される** | ところが。／違うんですって。／合っているんです。 |
| 3 | **自分の言葉で言い直す** | ぜんぶ、流れるものを思い通りに動かす仕事なんですよね／ってことですよね |

**ep003 の冒頭が原型**：「人が街から消え始める温度だそうです。だそうです、と言ったのは、
私も先週まで知らなかったからで。猛暑日って、三十五度からじゃないですか。
てっきりそこからだと思ってました。違うんですって。」

事実を詰めると、この3拍が真っ先に押し出される。**事実の点数より3拍を優先する。**

## 文は短く切る（間はここで作る）

**平均文長18字以下。**読点でつなぐより、句点で切る。TTS は読点より句点で確実に区切る。

- ❌ その隣では、別の機械が静かに回っていて、装置の中を真空に保つポンプです
- ⭕ その隣では。別の機械が、静かに回っています。装置の中を、真空に保つ、ポンプです。

**間を置きたい場所は、一語だけの文にする。**「荏原製作所。」「ところが。」「荏原は。逆なんです。」
社名・転換の接続詞・言い切りを単独の文にすると、その前後で必ず切れる。

## フィラー（1回に15〜20個）

**フィラーは口癖ではなく、間の代わり。**完全な無音は TTS では作れないので、
「意味の薄い音」で時間を稼ぐ。実際の喋りも、無音より「えー」のほうが多い。

置く場所：**数字の直前**（えーと、三百三十五億円）／**話題転換**（で。あの、）／
**思い込みを言う前**（私、なんか、）／**訂正のあと**（ところが。えー。）／**言い足すとき**（まあ、）

使う語：`えー` `えーと` `あの` `まあ` `うん` `ええ` `なんか` `で。` `そう。` `ね。`
ホストで選ぶ。三崎は軽いもの（あの・で・うん）、戸倉は低いもの（まあ・ええ・そうですね）。

## 尺と字数（2026-08改）

**6分・1,900〜2,200字。**5分1,700〜2,000字（毎分340〜400字）は速すぎて間が入らなかったため延ばした。
字数は増えるが、増分は事実ではなく**咀嚼・短文・フィラー**に使う。

## 書いたら
`python3 scripts/check.py episodes/<id>` を実行する。**文字数を目視で判断しない。**
平均文長・フィラー個数・咀嚼の拍も検査が数える。
下限割れしたら、未消化の facts ではなく**咀嚼の拍を増やして**埋める。
