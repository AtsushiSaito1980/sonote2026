# note 記事＋概要欄

## note は独立媒体
**ラジオ・放送・番組・音声・リスナーへの言及と導線を一切置かない。** 素材（brief・facts）は共有するが、記事として一から構成する。語り手は香月名義の編集部文体（芸人口調を使わない）。

## 文体：事実は言い切る、解釈は開く（personas/kazuki.md「借りて書く」）

記事は他人の取材・調査・開示の上に成り立つ。**断定してよいのは出典が言っていることまで。**そこから先の読みは、編集部の解釈として開く。謙虚さは断り書きや謝辞の一文で示すのではなく、**本文の言い回しそのものに出す**。

| ❌ 借り物の上で威張る | ⭕ 借りている自覚がある |
|---|---|
| 〜という装置なのである。 | 〜という装置なのだろう。 |
| 対象外の業界は存在しない。 | 対象外の業界は見当たらない。 |
| この赤字は必然的に生じる。 | この赤字は構造的に生じるものだろう。 |
| 三つの条件が要る。 | 成立には三つの条件が要りそうだ。 |
| 〜すればいい。／〜が早い。 | 〜のがよさそうだ。／〜から始めたい。 |

- **留保の言い回しは散らす**：〜のようだ／〜だそうだ（伝聞）／〜と読める／〜とみられる／〜のだろう／〜かもしれない。「〜と思う」の連発は読みにくい（`scripts/check.py` が回数を見る）
- 強い主張ほど本文で出どころを見せる（「報道によれば」「届出書の説明では」「会見では」）
- **日付・数値・固有の事実はぼかさない。**留保は1文に1つまで。全部を「かもしれない」にしない（わかりやすさを守る）
- 「編集部なりに整理した見方である」のような立場表明の決まり文句や、奥付の謝辞は置かない。**謙虚さは文面に出す**

## 見出しは、それだけ読んで中身が想像できること

章タイトルは比喩で凝らない。**その章に何が書いてあるかを、普通の言葉で言う。**

| ❌ 比喩で締めた見出し | ⭕ 中身が分かる見出し |
|---|---|
| 一、制度の時計 | 一、義務の中身と、施行までの日程 |
| 二、号砲の前に開いた店 | 二、施行前にもう開いている、四つの売り場 |
| 三、解剖 — 「引く」の構造 | 三、重さを取り除くと、勝負の軸が変わる |
| 四、この手の乗り方 | 四、自社の資産を、どの機能に当てはめるか |

- **`解剖 —` を見出しに付けない。**分析の章でも、何を分析したかを書く
- **`この手の〜` を見出しにしない。**「自社で試すなら、どこから」「自社の無料サービスに当てはめる」など、読者が何をする章かを書く

## 「手」に引っぱられた言い回しを避ける

番組名の「手」は本文の語彙ではない。本文で `この手` を主語にすると、毎回同じ癖の文章になる。**その回の中身を指す具体的な名詞に置き換える**（「無償公開は」「時間の置き場所を動かすことには」「この収益設計は」）。
`きょうの手` カードの見出しだけは残す。それ以外に「手」を持ち込まない。

## 制作の道具は、記事に出さない

note は外部公開。**どうやってネタを選び、どう作っているかは、こちらの持ち物**であって読者に見せるものではない。以下は記事にも概要欄にも書かない。

| 出さないもの | 代わりに |
|---|---|
| 手・動機・風の記号（`OP12` `MO1` `TW3`）とその一覧名 | 記号を使わず、その回の中身を普通の日本語で説明する |
| 「トリガ」「掛け味」「事実カード」「数字の系統」「並走句」「取材話法」 | 「きっかけになったニュース」など読者に通じる言葉 |
| 密度・型番号・巡回棚・ボツネタ・検査レポートへの言及 | 触れない |

**タグ欄は置かない。** 分類は `brief.yaml` と台帳に残っているので、記事に書く必要がない。
`scripts/check.py` が機械判定で弾く（記号や内部用語が残っていると FAIL）。

## 固定フォーマット（2,500〜3,500字）
1. **きっかけになったニュース**（冒頭・引用ブロック）：媒体名または発表主体・発表名・公開日
2. 本文（図解・年表・データ欄を活用）
3. **きょうの手**カード：教訓一行（**応用可能な原則の形。警句不可**）／使いどころ／最初の一歩（動詞終わり）
4. **データ**：主要数値を正確値で（ラジオで丸めた分もここに）
5. 出典（列挙）
6. 奥付：`記事中の数値・事実は文末の出典に基づき、表現は編集部が独自に構成したものです。企業名・商品名は各社の商標です。本誌の制作には生成AIを活用しています。`

- 手法の正式名（デザイン思考・逆設定法・ERRC等）は **note でのみ**扱ってよい。ただし**自分の分類体系は別**で、これは出さない
- 読者募集・拡散施策は置かない

## shownotes.md（配信概要欄）
先頭に「▼ トリガになったニュース」、その後に note 導線、そのほかの出典、末尾に AI 制作表記。
**台本本編には注釈・免責・出典を入れない。それらは全部ここが背負う。**
