# note 記事＋概要欄

## note は独立媒体
**ラジオ・放送・番組・音声・リスナーへの言及と導線を一切置かない。** 素材（brief・facts）は共有するが、記事として一から構成する。語り手は香月名義の編集部文体（芸人口調を使わない）。

## 固定フォーマット（2,500〜3,500字）
1. **今回のトリガ**（冒頭・引用ブロック）：媒体名または発表主体・発表名・公開日
2. 本文（図解・年表・データ欄を活用）
3. **きょうの手**カード：教訓一行（**応用可能な原則の形。警句不可**）／効く日／最初の一歩（動詞終わり）
4. タグ：手（OP）・動機（MO）・風（TW）
5. **データ**：主要数値を正確値で（ラジオで丸めた分もここに）
6. 出典（列挙）
7. 奥付：`記事中の数値・事実は文末の出典に基づき、表現は編集部が独自に構成したものです。企業名・商品名は各社の商標です。本誌の制作には生成AIを活用しています。`

- 手法の正式名（デザイン思考・逆設定法・ERRC等）は **note でのみ**扱ってよい
- 読者募集・拡散施策は置かない

## shownotes.md（配信概要欄）
先頭に「▼ トリガになったニュース」、その後に note 導線、そのほかの出典、末尾に AI 制作表記。
**台本本編には注釈・免責・出典を入れない。それらは全部ここが背負う。**
