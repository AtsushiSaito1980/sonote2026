[calm] で。計画の輪郭から。八月十三日、種子島でジャクサが探査機の機体を公開しました。調べてみたら、これがかなり大きい。名前はエムエムエックス。火星の衛星、フォボスに着陸して、砂と岩石を十グラム以上持ち帰る計画です。

機体は約四.五トン。ジャクサの月や惑星の探査機では、最大です。作ったのは、三菱電機。ことしの十月から十一月ごろに打ち上げて、帰ってくるのは二〇三一年度。約五年の旅です。

フォボスは、火星から六千キロほどの近さを回る、直径二十から三十キロの小さな月。『世界初の、火星圏からのサンプルリターン』と位置づけられているそうです。月の石も、小惑星の砂も、人類はもう持っている。でも、火星のそばの砂は、まだ誰も持っていないんです。

さて。砂を持ち帰って、どうするのか。売るのか。売れるのか。

[serious] 売りません。[pause]

ここからが、お題の答えです。三つ、あります。

[curious] 一つ目。砂は、売らずに配る。そして、交換する。配るんです。

前例があります。はやぶさ2です。小惑星から約五.四グラムの砂を持ち帰って、世界の研究機関に配りました。そして日米の合意で、ナサが別の小惑星から持ち帰った砂と、一部を交換したそうです。砂と、砂を。

うん。物々交換なんです。値札のつく市場より先に、交換の経済がある。なんか、いいですよね。

銀行員のころの言葉で言い直すと、これは通貨の発行に近い。世界に十グラムしかないものを持っている国は、世界中の研究と、対等に取引できる。分析する権利そのものが、通貨になるんです。お金では、買えない。持っている者どうしでしか、取引できない通貨です。

[bright] で、二つ目。探査機の「枠」が、売り場になる。枠です。

エムエムエックスには、フランスとドイツが一緒に作った小さな探査車と、ナサの観測装置が載っています。機体の枠を、各国が分担する。載せてもらう側は開発と分担を持ち寄り、載せる側は仲間と信用を得る。

一機の探査機が、国際協力の売り場になっているわけです。相乗りの、バスみたいなものですね。

そして三つ目。ここが、いちばん商売の話です。飛んだ、という実績。実績です。

[calm] 宇宙の機械は、性能の数字だけでは売れません。カタログでは、足りない。実際に宇宙へ行って、動いて、帰ってきたか。この実績が、資格になります。入札の、パスポートです。

五百五十三億円の計画は、三菱電機をはじめ、関わった会社に「火星圏まで行って戻った」という値札を作る。次の受注、国際共同、その次の商談で、この値札が効いてくる。砂は国の科学に、実績は企業の商売に残るんです。

ここから、商売の解剖です。きょうの手は、モノより先に、権利と実績を売る。三つに分けます。

一。売れないモノには、権利という形があります。あるんです。データ、検証結果、一点物の成果。モノ自体を売れなくても、「分析する権利」「先に使う権利」は配れて、交換できて、時に通貨になる。

[warm] 二。自分の計画に、まあ、他人の枠を作る。全部を自前で埋めず、載せたい人に枠を開けると、費用の分担と、仲間と、信用が入ってくる。

三。実績は、それ自体が商品です。とくに「初めて」の実績は、あとからお金で買えない。順番が、すべて。目先の採算が合わない仕事でも、そこでしか手に入らない実績があるなら、値札の付け方が変わります。

ここだけ持って帰ってください。五百五十三億円は、砂の値段ではありません。権利と、枠と、実績。売れないモノの後ろにある三つの商品の、開発費です。

今週の宿題です。自社にある「売れないが、価値はある成果」を、ひとつ挙げてください。実験データ、検証済みの記録、一度きりの実績。それを、権利として配るか、枠として開けるか、実績として名刺に刷るか。どの形なら商売になるか、書き出してみてください。
