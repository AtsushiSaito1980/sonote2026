2なぜ一周目では儲からないのか

貸すということは、商品の代金を自分が先に払っているということ。売り切りなら今日入る金を、何年もかけて回収する形に変えている。

売り切り

仕入れる
→
売る
今日、代金が全額入る
→
終わり
その後の関係はない

貸して回す

仕入れる
代金は自社が先に負担
→
一周目
月額が少しずつ入る。まだ元は取れない
→
二周目・三周目
ここでようやく超える
創業当時、業界からはこういう趣旨の反応があったという——「家具を貸して回す商売は成立しない。運ぶ費用が見合わない」。一周で回収しないと決めた以上、二周目以降の手間をどれだけ削れるかが、そのまま成否になる。

3調べたら、直す前提で作られていなかった

三年ほど前、社内で洗い出された困りごと。

1

部品が足りない

届いた時点でも、返ってきた時点でも、部品がそろっていない。

2

種類が多すぎる

ソファ1点に部品が100以上。管理も補充も追いつかない。

3

取り寄せられない

メーカーから部品単位では買えない。

根本原因は単純だった。家具も家電も、買った人が最後まで使う前提で設計されている。だから分解する前提がない。貸す商売を始めたのに、貸すのに向いた商品が売っていなかった。

5持ち物を、いちばん傷む単位で分けて持つ

在庫を商品ごとではなく、部品ごとに一つずつ管理している。

一体で持つと

テーブルの天板だけが傷んでも、一台まるごと使えなくなる。無事な脚まで一緒に退場する。

分けて持つと

天板だけ替えれば済む。脚は無事なまま次の部屋へ行く。ベッドなら板ごと、テーブルなら天板と脚を別々に。

6重さは、自分で持つ分と外に出す分に割る

うまくいっている話に聞こえるが、構造は重いまま。貸す数を増やすほど、先にモノを買う必要がある。

自社で保有する在庫 リース取引枠で外に出す分（最大3億円）
2023年4月に始まった取引が拡大し、去年（2025年6月）に枠は最大3億円まで広がって家電も対象になった。全部自前か全部外注かの二択にせず、増やす分だけを外に出している。※図の比率はイメージで、実際の保有比率は非公開。

家電を売る会社が、なぜ家電を売らない側に出資するのか。公式リリースを読むと、出資理由に「回収した家電を再生・検査して再提供してきた経験」が挙げられていた。売る側の「回収して直す部門」と、貸す側の「回して稼ぐ仕組み」は、同じ方向を向いている。

8解剖 — 条件と動作

1

二周目の手間を、設計の段階で先に削る

部品を減らす・共通にする・分解できるようにする。回収を後ろにずらす商売は、後ろの作業が軽くないと成立しない。

2

持ち物は、いちばん傷む単位で分けて持つ

天板と脚を別々に管理すれば、傷んだ側だけ替えられる。一体で持つと、一か所の傷で全部が使えなくなる。

3

重さは、自分で持つ分と外に出す分に割る

在庫は自社、増やす分の資金はリースの枠。全部自前か全部外注かの二択にしない。

他業界への持ち出し方。工場の設備、店の什器、業務の仕組み。「買って、壊れたら捨てる」で回っているものは、たいてい直す前提で作られていない。修理の見積もりが新品より高くなる、という経験がその証拠になる。
