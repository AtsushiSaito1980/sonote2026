きょうの手
消えてなくなる側で、稼ぐ。
回路を描いているのは「光が当たると酸を出す粉」。ADEKAが光酸発生剤の生産能力を約2倍へ——装置は売り切り、材料は焼くたびに消える。

数字で見る

生産能力
約2倍
千葉工場に生産ラインを増設（2026/8/20発表）
投資額
約10億円
2027年1月着工・2028年2月完成
営業運転の開始
2028年9月
2年以上先。しかもこれでも「2年前倒し」
EUVの波長
13.5nm
現在主流のArFより10倍以上短い。光が弱い分レジストの工夫が要る

粉が、線を描いている

レジストに光を当てる
ウェハーに塗った感光性の膜。EUVは波長13.5ナノメートル
→
粉が酸を出す
光酸発生剤。ごく微量だが、樹脂の溶けやすさを変える
→
当たった所だけ溶ける
残った部分が回路の線に。焼くたびに材料は減る

半導体で稼ぐのは装置でもチップでもない——消えていく材料の側にも、強い商売がある。

量が少ないほど弱い、とは限らない

思い込み使う量が少ない材料は金額が小さく、買い叩かれる
→
実際工程のレシピに名指しで書かれる。替えれば線幅も歩留まりも変わり、検証のやり直しになる
大事なのは、使われる量ではなく、外せるかどうか。検証済みの材料は、金額の小ささとは無関係に強い。

この構え方を、自社で使うなら

1

消える側に回る

売り切りは一度きり。使うたびに減るものは、顧客の稼働がそのまま自社の伝票になる。

2

レシピに名前を入れる

手順書に指定され検証済みになれば、替えるコストのほうが高くつく。量ではなく代替可能性。

3

山より前に建てる

設備は建つのに時間がかかる。需要が見えてから動くと間に合わない——前倒しの2年が壁になる。

自社が関わる製品で「使うたびに減っていくもの」を特定し、そこに自社の技術や名前が入り込めないかを検討する。
使いどころ：売り切り型の製品・設備で、リピート受注が読めずに苦しんでいるとき
最初の一歩：主要顧客の工程で「毎回消費されるもの」を列挙し、自社が供給できるものに丸を付ける
