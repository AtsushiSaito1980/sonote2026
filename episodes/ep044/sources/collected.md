# ep044 収集素材（原本）

収集日：2026-08-30／region: 国内
テーマ：売ってはいけない食べ物の工場を、ルールができる前に建てる

**この回で守る線（収集の時点で決めておく）**
- **培養肉の是非を論評しない。**安全か危険か、受け入れるべきかは扱わない
- **畜産の環境負荷（温室効果ガスの割合など）は使わない。**是非論が主題になる（ng.yml）
- **ep042（さかなドリーム）と芯を分ける。**「天然にいない」「人工の肉」という言い方をせず、
  焦点を食べ物ではなく**工場と規制の時間差**に置く
- 個人名・参画企業名は台本で使わない（§3）。**記事では実名を書く**

## S1｜トリガ：牛の培養肉、来年1月にも試験生産へ
- 媒体：**読売新聞オンライン**（Yahoo!ニュース転載でも同一記事）
- 配信：**2026年8月24日（月）14:00**
- URL: https://news.yahoo.co.jp/articles/d21902a23fbd33cc266f41d3c52f5fd371003222

### 記事にある事実（原文の言い回しを含む）
- 「培養肉未来創造コンソーシアム」で、**「２３年に発足」**。大阪大の**松崎典弥教授（応用化学）**を中心に、
  **島津製作所、TOPPANホールディングス**などが参画

- **「本物に近い形状を持つ培養肉の生産ラインは世界初」**とされる
- 試験生産は**「来年１月にも始める」**（＝2027年1月）
- 設置場所：**阪大吹田キャンパスの研究棟**
- **「細胞の培養から肉の成形まで約１か月で製造」**
- 牛の**筋肉・脂肪細胞を培養し、3Dプリンターで繊維状にしたものを束ねて成形**
- **「１００グラム４５００円程度での販売を目指す」**
- **「２０３０年度の商業化を目指す」**
- **「国は培養肉の販売に向けた指針作りを進めており」**（＝現時点で国内販売は認められていない）

### この記事の位置づけ（重要）

## S3｜技術の中身（JST共同発表・準一次）
- URL: https://www.jst.go.jp/pr/announce/20210824-2/index.html
- 発表：2021年8月24日「３Ｄプリントで和牛の“サシ”まで再現可能に」
- 従来の培養肉は**ほとんどが筋繊維のみのミンチ状**で、食肉の複雑な組織構造の再現は難しいとされてきた
- この技術は、**筋・脂肪・血管の異なる繊維組織を3Dプリントで作り、金太郎飴のように折り重ねて統合する**
- ※ 2021年の発表なので、使うなら**時期を明示する**（§4）

## S4｜背景（使い方に注意）
- 培養肉は世界のたんぱく質不足への対応として位置づけられている（コンソーシアム公式）
- **畜産の環境負荷（牛肉1kgに穀物11kg、温室効果ガス総排出量の14%など）は、
  是非論が主題になるため全成果物で使わない**（ng.yml）

## 使わないもの（rejected）

| 項目 | 理由 |
|---|---|
| 培養肉の安全性・是非、受け入れの可否 | **論評しない。**この回は工場と規制の時間差の話 |
| 畜産の環境負荷の数字（穀物11kg・温室効果ガス14%） | 是非論が主題になる（ng.yml） |
| 「天然にいない肉」「人工の肉」という言い方 | **ep042 と芯が重なる**うえ、食べ物への値踏みに聞こえる |
| 「値段を自分で決める」という筋立て | **ep042 の芯そのもの。**この回では使わない |
| 商業化の年度（2030年度／2031年） | **出典が食い違う。**台本では使わず、記事で両論併記 |
| 投資額・ラインの建設費・売上計画 | 記載なし |
| 参画企業の個別の役割分担 | 一次で確認できていない |
| 個人名（松崎教授）・参画企業名 | 台本では不使用（§3）。**記事では実名を書く** |
| 海外の培養肉企業との比較・優劣 | 値踏みになる（§2-6） |
