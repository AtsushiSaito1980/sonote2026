# ep040 読み上げ用の台本（ブラウザの音声読み上げ向け）

## 『その手があったか』｜抜けたら止まる人を、先に数える

### ホスト：三崎アオイ／約12分／ElevenLabs 用の `script_tts.txt` とは別物

### 書き方の方針（読み上げ対象外）

- **相手は無感情な機械の声。**演技で運べないものは、言葉で運ぶ
- フィラー（まあ・ええ・うん・そう。・で。）を置かない。抑揚が無いと、意味のない音になる
- 極端に短い単独文を連ねない。ブツ切れに聞こえる。1文はおおむね25〜50字
- 反語と「〜ですよね」を減らす。上がり調子が付かないので、ただの平叙文に聞こえる
- **接続詞を省かない**（ところが／そのため／一方で／つまり／ここまでが〇つめ）
- **今どこを話しているかを、こまめに言う。**耳だけの12分は、道しるべが無いと迷子になる
- 数字は必ず、直後に意味を添える。単体で置かない
- **分からなかったことは、分からなかったと言う。**尺があるぶん、都合の良い話だけにしない
- 間は改行。`[pause]` などのタグは使わない
- 英字はすべてカナに開くか、日本語に言い換える。読み上げが崩れるため
- **個社名・個人名は出さない。**死去や体調不良を誰かの落ち度として扱わない。尺があるぶん、その断りを本文で厚くする
