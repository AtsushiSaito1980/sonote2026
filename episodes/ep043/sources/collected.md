## S2｜PDACの保険収載承認（同社サイト・一次）
- URL: https://db.bionicm.com/powered-prosthetic-knee-bio-leg-receives-insurance-coverage-approval-in-the-u-s/
- 承認日：**2024年5月24日**
- 取得コード：**L5828／L5845／L5848／L5856／L5859 の5つ**
- L5859 の定義（原文）："code L5859 is assigned to prosthetic knees with the function of assisting knee bending and extending using motor power"
  ＝ モーターの力で膝の曲げ伸ばしを補助する機能を持つ義足膝に割り当てられたコード
- **アジア初（原文）**："it is the first time that a prosthetic knee developed by an Asian manufacturer, including those from Japan, has received this code approval"
- FDA：**2023年7月にクラスII医療機器として登録**
- 同社の位置づけ（原文）："the approval of Bio Leg's power assist function for medical insurance coverage by PDAC is a turning point in the prosthetic industry"
- **保険が効くと患者側の負担がどう変わるかの具体（金額）は、このページに記載なし**

### この回の芯（Q1）
使うのは切断した本人だが、**払うのは保険**。だから、払う側の償還表にコードが載らないかぎり、
どれだけ良い義足でも「買えない商品」のままになる。**払う側の台帳に名前が載るまでが開発。**

## S3｜CEO本人の署名記事「私がロボット義足を作るまで」Part 2（一次・動機と制約）
- URL: https://db.bionicm.com/column/ceo02/
- 公開：**2021年8月**

### 引っかかった瞬間
- 電機メーカー勤務中、日常の移動で課題が増えた。原文：「電車など降りた後の人混みはゆっくり歩くのには意外に歩きづらい環境でした」
- 「膝がガクンと折れてしまうリスク」が増し、**何度も転倒を経験**
- そのときの心境（原文）：「ふと、**『自分の脚を作れないか？』**という思いが生まれました」

### 反対・制約・孤立の記録（型3に必須）
- **ロボット開発部署への異動申請は落選**
- 社内起業プログラムへの応募も見送り。理由（原文）：「ロボットのバックグラウンドがないため、自分でできるか不安」
- 退社を伝えたとき（原文）：**「上司や周囲の方々は『もっと会社に勤めた方がいいよ』と言ってくださいました」**
- 大学院での研究初期（原文）：「義足の開発の進捗はあまり無かったので、少し不安に感じました」

### 進んだ理由
- 原文：「自分は義足ユーザーでもあり、エンジニアでもある。そして今、義足に対して様々な不便を感じている。ならば**『自分で解決すべきではないか？』**」
- 「自分のしたいことができる道を選びました」→ 2015年冬に東京大学大学院情報理工学系研究科の博士課程へ
- 学内プログラム（Todai to Texas）に応募し、SXSW出展を目指したことが「文字通り私、そして義足開発の運命を変え、BionicMの最初の一歩となった」

## S4｜経歴と事業の輪郭（nippon.com・準一次）
- URL: https://www.nippon.com/ja/japan-topics/e00186/
- 公開：**2021年8月11日**（※ 窓外。台本では時期を明示する）

| 年 | 事柄 |
|---|---|
| 1987年 | 中国貴州省生まれ |
| 1996年 | **9歳で骨肉腫により右脚を切断** |
| 2009年 | 交換留学生として東北大学へ |
| 2010年 | 東京大学大学院へ進学。**国の公的補助を使って、初めて義足を装着** |
| 2013年 | 修士課程修了、電機メーカーに入社 |
| 2015年 | 東京大学大学院博士課程へ |
| 2018年12月 | BionicM株式会社 設立 |

- 切断前はバスケットボールに熱中していたが、その後できたことができなくなって落ち込んだ
- **中国では障害者への補助金などの支援制度が充実しておらず、高価な義足を入手できず、松葉づえを使うしかなかった**
- 従来の義足：「受動式」（動力なし）が主流。BionicM の製品は複数のセンサーで動きを読み取り、**モーターで歩行をアシスト**する
- 当時の従業員：17名／販売：日本と中国（深圳に子会社）／2020年に5億5,000万円を調達
- 本人の言葉（趣旨）：脚を切断することを誰も望んではいない。それでも切断せざるを得ないとき、**かっこいい義足を作りたい**
