# ep010 台本（人間レビュー用）
## 『その手があったか』｜商品より先に、売り場を動かす
### ホスト：三崎アオイ／型1 一本深掘り型／6分／density: balanced
### 2026-08改：咀嚼の3拍・平均文長18字以下・フィラーで間を作る

はい、始まりました。『その手があったか』。世の中の商売の、その手を持ち帰る時間です。三崎アオイです。

えー、まず。ある八百屋の話を、させてください。

十三年前の冬。東京の、麻布十番。酒屋さんの店先の一角を借りて、産地から届いた野菜を並べた、小さい店です。

一日の売り上げは、一万円ほど。

夕方になると、売れ残った野菜を袋に詰めて。知り合いの会社を回って、買ってもらう。そういう日々だったそうです。

で。この八百屋をやっていた会社に、この八月、大きな知らせが届きました。その話は、あとで。

会社の名前は、コンペイトウ。いま何をしているかというと。よその会社のオフィスに、冷蔵庫を置かせてもらう商売です。

中身は、サラダや、お惣菜。オフィスでやさい、という名前のサービスで、働いている人は、一品百円から買えます。

百円で野菜を売って、儲かるのか。私も、思いました。

うん。カラクリは、払う人でした。百円で足りない分は、冷蔵庫を置いている会社のほうが、月ぎめの利用料として払っているんです。

食べるのは、社員。足りない分は、会社。ひとつの冷蔵庫に、財布がふたつある、ってことですよね。

さて。きょうの本題は、この形を思いつくまでの話です。

創業した人は、もともとコンサルの会社で、農業の担当をしていました。畑はいいものを作るのに、売る先が詰まっている。その光景を、仕事で毎日、見てしまったそうです。

それで会社を辞めて、二〇一二年に仲間と起業します。

最初は、産地から直接届ける通販サイト。これが、ふた週間で注文が止まりました。次が、さっきの八百屋で、一日一万円。

まあ、モノはいいのに、売れない。

その売り歩きの先で、知り合いの経営者に、言われたそうです。『野菜を持って帰るのは、電車だと大変でしょう。その場で食べられるようにしたほうがいいよ』。

それで、知り合いのオフィスで、試しに置いてみた。ここで、芯になる発見をします。

オフィスで気軽に手が伸びる値段は、百円まで。でも百円だと、原価より安い。

ふつうなら、ここで畳みますよね。

あの、この人は。値段を上げる代わりに、もうひとりの払い手を、探しに行った。社員の健康のためなら、会社が出すんじゃないか。

そして二〇一四年の四月。会社が月ぎめで補助する形にして、いまのサービスを始めます。

よく見ると、動いたのは、売る場所だけなんですよね。畑の直送から、店先へ。店先から、オフィスの中へ。

もちろん、順風では、ありません。始める前から、周りには『農業なんて、絶対うまくいかない』と言われていたそうです。本人も、駄目なら会社員に戻るつもりだった、と。

八百屋のころは、夜は納涼船でビールを注いで。フットサルの審判もして、生活費を作っていた。

これ、現場やった人ならわかると思うんですけど。商売そのものより、続けるためのお金の工面のほうが、心を削るんですよね。

置き型に変えたあとも、資金は二度、底をつきかけた。小さい娘がふたりいて、食わせていけるのかと眠れない夜があったと、本人が書き残しています。

で。その会社に届いた知らせが、八月十二日の、上場承認です。九月十一日に、東京証券取引所のグロース市場に上場する予定です。

契約している会社は、六千六百四十四社。一日一万円の店から、ここまで来ています。

しかも聞いてみたところ。強いのは、東京よりむしろ地方だそうです。地方の銀行が取引先に紹介して、広がっているとのことでした。

私、置き型は都心のものだと、思い込んでいました。ええ、ここは、知りませんでした。

黒字は、ことしの五月までの九ヶ月で、初めてはっきり出たそうです。創業から、十三年。まあ、長いですよね。

さて。ここから、商売の解剖です。きょうの手は、商品より先に、売り場を動かす。三つに、分けます。

一。商品が売れないとき。商品を変える前に、お客さんが受け取る場所と手間のほうを、変えてみる。モノは同じでも、場所が変われば、別の商売になります。売れなかったのは、野菜そのものより。持って帰る手間のほうだった、ということですよね。

二。動かす先は、お客さんが面倒くさそうにしている場所です。その顔を見たら、書き留めて終わりにせず。そこへ、売り場ごと持っていけないかを、考える。

三。値段が原価を割るなら。そこで畳まずに、使う人と払う人を、分けられないかを探す。会社。組合。自治体。本人の財布の外に、その面倒を解決したい人がいることが、あります。

たとえば、クリーニング屋さんが。店で受け渡しする代わりに、会社の入り口に、集配の棚を置く。あの感覚ですね。

今週の宿題です。あなたのお客さんが、あなたの商品を持って帰るのを面倒がっている瞬間を、ひとつ探してください。見つかったら。その面倒が起きている場所へ、売り物ごと動かせないか。考えてみてください。

きょうの手は、商品より先に売り場を動かす、でした。あなたの業界の当たり前、ひとつだけ動かすなら、どこですか。答えがひとつでも浮かんだら、それが、あなたの企画書の一行目です。それでは、また明日。三崎アオイでした。
